# Sequence Alignment (Human vs Bovine RHO)

This folder contains the sequence alignment data between the human RHO (AlphaFold model) and the bovine RHO template.

## Tools Used
- **Clustal Omega** (EBI)

## Results
- **Sequence Identity:** 93.4%
- **Residues Overlap:** 348
- **Gap Frequency:** 0.0%

## Files Included
- `Bovine_RHO_sequence.txt`: Raw sequence for bovine RHO.
- `human_RHO_sequence.txt`: Raw sequence for human RHO.
- `multiple_sequence_alignment.aln-clustal_num`: The alignment file in Clustal format.
- `Percent_Identity_Matrix.pim`: The identity matrix generated by Clustal Omega.
